# Controllers Directory

This directory contains ASP.NET Core Controllers that handle incoming HTTP requests.

## Structure

- **ProductsController.cs** - Product management endpoints
- **OrdersController.cs** - Order management endpoints
- **ImportController.cs** - Data import endpoints (Excel/CSV)

## Best Practices

- Keep controllers lean and focused
- Delegate business logic to services
- Use async/await patterns
- Return appropriate HTTP status codes
